## 📲 How to Login in 30 Seconds

1. **Enter Phone Number**: Open TG Drive and type your Telegram registered phone number with international country code (`+XX ...`).
2. **Enter Telegram Code**: Check your official Telegram chat app to receive your 5-digit verification code.
3. **2FA Password (Optional)**: If you have Cloud Password enabled on Telegram, enter your 2-step verification password.
4. **Instant Access**: Your unlimited cloud drive is ready to use!
